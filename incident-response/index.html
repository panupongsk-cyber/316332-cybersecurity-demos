Welcome to the incident-containment and response simulator for Sommuti Co., Ltd.
You'll make decisions on behalf of 3 employees, each facing a different type of cyber emergency.
Each emergency is split into 3 steps following the real incident-response playbook — Immediate Action, Report & Follow-up, and Absolute Prohibition — each step is an independent question testing a different part of the playbook. The story always continues assuming the correct path was taken in the previous step, so you can practice every step regardless of whether the previous one was answered correctly.
